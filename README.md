# 🚗 Sistema de Gestión de Concesionario

Un sistema interactivo en consola desarrollado en Python aplicando los principios fundamentales de la Programación Orientada a Objetos (POO) y la persistencia de datos.

## 📌 Características
* **Herencia y Estructura POO**: Implementación de una clase base `Vehiculo` y clases hijas `Carro` y `Moto` con sus respectivos atributos y métodos.
* **Persistencia de Datos**: Carga y guardado automático de información en formato `JSON` para mantener el inventario guardado entre ejecuciones.
* **Manejo de Excepciones**: Validación y control de errores al leer archivos inexistentes o vacíos.
* **Menú Interactivo**: Interfaz en consola para registrar vehículos y visualizar el inventario actual.

## 🛠️ Tecnologías Utilizadas
* Python 3
* Programación Orientada a Objetos (POO)
* Módulo `json` y manejo de archivos (`with open`)
